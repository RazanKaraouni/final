# MugStore

This is my final project. It is a small mug shop with two parts: a portfolio website and an admin website.

## How to open it

1. Start Apache and MySQL in XAMPP.
2. Create a database named mugStore.
3. Put the project folder inside htdocs.

Portfolio:
http://localhost/final/portfoilio/index.php
Admin login:
http://localhost/final/login.php

## Admin login

Username: admin
Password: admin123

The first time the site connects and the users table is empty, it creates the admin account.

## What the admin can do

- Add, edit, and delete products
- Add, edit, and delete categories
- Add, edit, and delete clients
- Add, edit, and delete users
